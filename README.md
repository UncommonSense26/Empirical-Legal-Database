# Empirical Legal Database

This repository holds the Empirical Legal Database. It was first published on
[Harvard Dataverse](https://dataverse.harvard.edu). Its DOI is listed in
[`CITATION.cff`](CITATION.cff) after the import runs. You can also use the
**"Cite this repository"** button on GitHub.

- `data/`: the dataset files, copied from Dataverse
- `metadata/dataverse_metadata.json`: the full original Dataverse metadata
- `CITATION.cff`: citation metadata that GitHub reads
- `.zenodo.json`: metadata for minting a Zenodo DOI from GitHub releases

See [MIGRATION.md](MIGRATION.md) for how the dataset was moved and how DOIs
work with GitHub.
